# วิธีเชื่อมระบบใบเสนอราคากับ Google Sheet

ใช้เวลาประมาณ 10–15 นาที ทำครั้งเดียว ใช้คอมพิวเตอร์จะสะดวกที่สุด

## สิ่งที่ต้องมี
- บัญชี Google (Gmail) ของบริษัท ที่จะเป็นเจ้าของข้อมูล
- ไฟล์ 2 ไฟล์จาก GitHub repo นี้
  - `apps-script/Code.gs` — โค้ดฝั่งเซิร์ฟเวอร์
  - `index.html` — หน้าเว็บ

---

## ขั้นที่ 1 · สร้าง Google Sheet
1. เข้า https://sheets.new (จะได้ Sheet เปล่าใหม่)
2. ตั้งชื่อไฟล์มุมซ้ายบน เช่น `ระบบเอกสาร P&I Electric`

## ขั้นที่ 2 · เปิด Apps Script
1. ในหน้า Sheet กดเมนู **ส่วนขยาย (Extensions) → Apps Script**
2. จะเปิดแท็บใหม่ มีไฟล์ชื่อ `Code.gs` อยู่แล้ว
3. ตั้งชื่อโปรเจกต์มุมซ้ายบน เช่น `ระบบใบเสนอราคา`

## ขั้นที่ 3 · วางโค้ดฝั่งเซิร์ฟเวอร์
1. เปิดไฟล์ `apps-script/Code.gs` ใน GitHub → กดปุ่ม **Copy raw file** (ไอคอนคัดลอก)
2. กลับมาที่ Apps Script ลบโค้ดเดิมใน `Code.gs` ทั้งหมด แล้ววางโค้ดที่คัดลอกมา
3. กด 💾 **บันทึก** (Ctrl+S)

## ขั้นที่ 4 · วางหน้าเว็บ
1. ใน Apps Script กดเครื่องหมาย **+** ข้างคำว่า "ไฟล์" → เลือก **HTML**
2. ตั้งชื่อว่า `index` (พิมพ์แค่ `index` ระบบจะเติม `.html` ให้เอง)
3. ลบโค้ดตัวอย่างในไฟล์ทิ้ง
4. เปิดไฟล์ `index.html` ใน GitHub → **Copy raw file** → วางลงไฟล์ `index`
5. กด 💾 **บันทึก**

## ขั้นที่ 5 · สร้างแท็บข้อมูลใน Sheet (รันครั้งเดียว)
1. กลับไปที่ไฟล์ `Code.gs`
2. ที่แถบด้านบน เลือกฟังก์ชัน **`setup`** แล้วกด ▶ **เรียกใช้ (Run)**
3. ครั้งแรกจะขอสิทธิ์:
   - กด **ตรวจสอบสิทธิ์ (Review permissions)** → เลือกบัญชี Google ของคุณ
   - ถ้าขึ้น "Google hasn't verified this app" ให้กด **ขั้นสูง (Advanced)** → **ไปที่ ระบบใบเสนอราคา (ไม่ปลอดภัย)**
     (ขึ้นเพราะเป็นสคริปต์ที่เราเขียนเอง ไม่ได้ส่งให้ Google ตรวจ)
   - กด **อนุญาต (Allow)**
4. กลับไปดู Google Sheet จะมีแท็บ `Customers`, `Products`, `Templates`, `Documents`, `Settings` พร้อมหัวคอลัมน์

## ขั้นที่ 6 · เปิดใช้เป็นเว็บแอป
1. ใน Apps Script กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอน ⚙ ข้าง "เลือกประเภท" → เลือก **เว็บแอป (Web app)**
3. ตั้งค่า:
   - **คำอธิบาย:** `เวอร์ชันแรก`
   - **ดำเนินการในฐานะ (Execute as):** **ฉัน (Me)** — ระบบจะเขียน Sheet ด้วยบัญชีของคุณ พนักงานไม่ต้องมีสิทธิ์แก้ Sheet
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคนที่มีบัญชี Google (Anyone with Google account)**
4. กด **การทำให้ใช้งานได้ (Deploy)**
5. คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) — นี่คือลิงก์ใช้งานจริง

## ขั้นที่ 7 · เปิดใช้งานครั้งแรก
1. เปิด URL `/exec` ในเบราว์เซอร์
2. ครั้งแรกระบบจะเห็นว่า Sheet ยังว่าง แล้วใส่ข้อมูลเริ่มต้นให้เอง:
   - ข้อมูลบริษัท พี แอนด์ ไอ อิเล็คทริค + โลโก้ + บัญชีธนาคาร
   - สินค้าตัวอย่าง 16 รายการ และเทมเพลตงานโซลาร์ 3 ชุด
   - **ไม่มี** ลูกค้าหรือเอกสารตัวอย่าง (เริ่มจากศูนย์)
3. มุมขวาบนจะขึ้น "บันทึกแล้ว ✓" แปลว่าข้อมูลเข้า Sheet แล้ว ลองเปิดแท็บ `Products` ใน Sheet ดูได้

## ขั้นที่ 8 · ใช้บนมือถือ
1. ส่ง URL `/exec` ให้ตัวเองหรือพนักงานทาง LINE
2. เปิดด้วย Chrome (Android) หรือ Safari (iPhone) — ถ้าเปิดในแอป LINE ให้กด "เปิดในเบราว์เซอร์"
3. กดเมนูเบราว์เซอร์ → **เพิ่มไปยังหน้าจอหลัก (Add to Home screen)** จะได้ไอคอนเหมือนแอป

---

## เมื่อแก้โค้ดรอบถัดไป
1. วางโค้ดใหม่ทับใน `Code.gs` / `index` แล้วบันทึก
2. **การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ (Manage deployments)**
3. กด ✏️ แก้ไข → **เวอร์ชัน: เวอร์ชันใหม่ (New version)** → **การทำให้ใช้งานได้**
4. URL เดิมใช้ต่อได้ ไม่ต้องส่งลิงก์ใหม่

## ข้อมูลอยู่ตรงไหนใน Sheet
| แท็บ | เก็บอะไร |
|---|---|
| `Customers` | ลูกค้า 1 แถวต่อ 1 ราย |
| `Products` | สินค้า รหัส ชื่อ หมวดหมู่ หน่วย ราคา |
| `Templates` | เทมเพลตงานติดตั้ง (รายละเอียดอยู่ในคอลัมน์ `data`) |
| `Documents` | เอกสาร 1 แถวต่อ 1 ใบ: เลขที่ ประเภท สถานะ วันที่ ลูกค้า ยอดรวม (รายการทั้งหมดอยู่ในคอลัมน์ `data`) |
| `Settings` | ข้อมูลบริษัทและการตั้งค่า |

- แก้ลูกค้า/สินค้าใน Sheet ตรง ๆ ได้ แล้วรีเฟรชหน้าเว็บ
- **ไม่ควร** แก้คอลัมน์ `data` ด้วยมือ ถ้าจะแก้เอกสารให้แก้ผ่านหน้าเว็บ
- ห้ามลบหรือเปลี่ยนชื่อแท็บ และห้ามสลับลำดับคอลัมน์

## ถ้ามีปัญหา
| อาการ | วิธีแก้ |
|---|---|
| หน้าเว็บขึ้น "ไม่พบแท็บ ..." | ยังไม่ได้รัน `setup` (ขั้นที่ 5) |
| หน้าเว็บขึ้น "โหลดข้อมูลไม่สำเร็จ" | ตรวจว่ากดอนุญาตสิทธิ์ครบ แล้วลอง Deploy เวอร์ชันใหม่ |
| มุมขวาบนขึ้น "บันทึกไม่สำเร็จ" | อินเทอร์เน็ตหลุด ระบบจะส่งข้อมูลอีกครั้งตอนบันทึกครั้งถัดไป |
| แก้โค้ดแล้วหน้าเว็บไม่เปลี่ยน | ต้อง Deploy เวอร์ชันใหม่ (หัวข้อ "เมื่อแก้โค้ดรอบถัดไป") |
| 2 คนออกเอกสารพร้อมกันได้เลขเดียวกัน | ระบบเปลี่ยนเลขของคนที่บันทึกทีหลังให้อัตโนมัติ และแจ้งเตือนบนจอ |
